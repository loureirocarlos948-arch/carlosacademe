Esta versão utiliza o armazenamento local do navegador para os alunos e definições. As notas, presenças e pagamentos são mantidos apenas durante a sessão. Para guardar todos os dados de forma permanente e partilhá-los entre computadores, será necessário ligar o sistema a PHP e MySQL.
